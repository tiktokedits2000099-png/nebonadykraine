Небо над Украиной - обновление режима украинской операции

Запуск:
1. Установить Node.js 18+.
2. Выполнить: npm start
3. Открыть: http://localhost:3000

В архиве:
- index.html - игра
- server.js - сервер, онлайн и таблица лидеров
- redis-api.js - API для Upstash Redis
- config.js - конфигурация
- render.yaml - деплой на Render
- package.json - запуск проекта

Обновления:
- расширенная операция «Длинная рука»;
- новые цели: командные пункты, РЛС и логистические узлы;
- разведка 0/3 и ослабление следующих волн;
- классы операций и лучший результат кампании;
- риск усиленного ответного удара после дорогого провала;
- улучшенные модели и отрисовка ударных дронов и ракет.
